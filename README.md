# What is this and why should it be used?
Within Berkeley Engineers and Mentors, there are two site coordinators
who are responsible for maintaining relationships with schools and school
districts in order to ensure that volunteers/mentors are assigned to
schools.
<br><br><br>
In addition to this role, site coordinators are also responsible for
assigning mentors to each school. This is a problem that can be solved
using linear solvers, among other approaches. As a result, I created
a program that can automatically assign mentors to different schools
across the Bay Area given certain requirements.
<br><br><br>
Included in this github repository are test files along with python
files for the creation of different classes and data preprocessing of
input excel files. If you are interested in using this program, feel free to
use the [link](https://beamsitecoordination.streamlit.app/)
<br><br><br>
For site coords, this [folder](
    https://drive.google.com/drive/folders/1SlLPxKwhpydhOq3QXoMPK-MlppTY8rFf?usp=drive_link)
contains the necessary python files, excel templates, and google form
template links to automate site assignments. If you want to use this program,
please adhere to these templates closely.
<br><br><br>
Lastly, if you would like to suggest any changes to this program or if you
